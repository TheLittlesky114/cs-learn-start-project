# C# 入门实践 · 控制台与综合小游戏

跟随唐老狮的视频教程所做的 **C# 控制台入门实践**，属于语法基础之后的第一批「动手练」项目。

仓库共 5 个独立可运行的控制台项目，从**控制台 API** 和**随机数**两组必备知识点开始，最后用一个完整的控制台小游戏「唐老狮营救公主」把它们串起来。所有代码都在 `Program.cs` 单文件内，按知识点用 `#region` 分段，配有中文注释，适合边读边跑。

- **语言 / 平台**：C# / .NET 10.0（`net10.0`），控制台应用（`OutputType=Exe`）
- **项目数量**：5 个独立 `.csproj`，由根目录 `c#实践.slnx` 解决方案组织
- **代码规模**：约 670 行
- **依赖**：仅 `System` 标准库，无第三方包、无外部资源

## 两个知识点

### 控制台 API（`必备知识点_控制台相关`）

把「怎么把画面画出来」需要的接口一次讲清：

- `Console.Clear()` 清屏；
- `SetWindowSize` / `SetBufferSize` —— **窗口**（可视区域）与**缓冲区**（可承载内容的总区域）是两个概念，必须**先设窗口再设缓冲区**，且缓冲区不得小于窗口、窗口不得大于控制台最大尺寸；
- `SetCursorPosition(x, y)` —— 控制台以左上角为原点、右为 x 正方向、下为 y 正方向；注意视觉上 `1y = 2x`，因为字符是宽字符；
- `ForegroundColor` / `BackgroundColor` 文字与背景色，改背景色后需要 `Clear()` 一次才整体生效；
- `CursorVisible` 光标显隐；
- `Environment.Exit(0)` 关闭控制台。

配套练习（`必备知识点_控制台相关练习题`）用这套接口做了一个红底黄字的方块：

- 用 `■` 表示角色，`WASD` 控制移动；
- **不是**每帧 `Clear()` 整屏，而是只擦除自己刚离开的那两个字符位再在新位置重绘，这是控制台动画的关键技巧；
- 水平方向步长为 2，因为一个汉字/方块占 2 个字符宽度；
- 用 `BufferWidth - 2` 与 `BufferHeight - 1` 钳制坐标，防止越界；
- 文件顶部另附调试笔记：`F9` 打断点、`F10` 单步、`F5` 继续执行、用监视窗口查看变量值。

### 随机数（`必备知识点_随机数`）

- `Random r = new Random();` 是固定写法；
- `r.Next()` 返回非负随机整数；
- `r.Next(100)` 返回 `0–99`；
- `r.Next(5, 100)` 返回 `5–99`；
- 带区间的重载统一是 **左闭右开**（含左端、不含右端）。

配套练习（`必备知识点_随机数练习题`）把它用在战斗数值上：每次用 `Next(8, 13)` 掷出攻击力，与固定防御力 10 比较，只有攻击力大于防御才按差值扣血，否则提示「未受到伤害」；按键推进回合，血量归零后输出「小怪兽已死亡」。

## 综合实践：唐老狮营救公主

`入门实践` 是本仓库的收尾项目（约 490 行），把控制台绘图、输入处理与随机数组合成一个可玩的完整游戏。

**玩法**

- 开始界面 `W` / `S` 切换选项、`J` 确认，可选「开始游戏」或「退出游戏」；
- 游戏中 `WASD` 移动玩家，走到 Boss 上下左右相邻格按 `J` 进入战斗，此后每按一次 `J` 打一回合；
- 击败 Boss 后原地出现公主，走到公主身边按 `J` 通关；
- 玩家血量归零则失败，进入结束界面，可「回到开始界面」或「退出游戏」。

**初始数值**

| 角色 | 图标 | 颜色 | 初始血量 | 攻击力 |
| --- | --- | --- | --- | --- |
| 玩家 | `●` | 黄 | 100 | 8–12 |
| Boss | `■` | 绿 | 100 | 7–13 |
| 公主 | `★` | 蓝 | — | — |

**实现要点**

| 关注点 | 做法 |
| --- | --- |
| 舞台 | 固定 50 × 30，同时设置窗口与缓冲区并隐藏光标 |
| 场景管理 | `nowSceneId` 标识当前场景，主循环 `switch` 分发；三个场景各有一个 `while` 内循环负责自己的输入 |
| 地图 | 用红色 `■` 逐格绘制四面墙，另有一条横向墙把舞台分成战斗区与信息区 |
| 移动与碰撞 | 先擦除再重绘；撞墙时钳制坐标，撞到存活 Boss 或尚未解锁的公主时把坐标「拉回」原位 |
| 战斗 | 双方轮流 `Random.Next(min, max)` 掷伤害扣血；每回合先按行擦掉旧战报再在固定行打印新战报，避免文字残留 |
| 跳出内循环 | 在 `switch` 中改 `isOver` / `isQuitWhile` 标识，回到外层 `while` 后再 `break` |

## 运行方式

需要安装 **.NET 10.0 SDK**。

```bash
# 运行小游戏
dotnet run --project "入门实践/入门实践.csproj"

# 运行控制台 API 演示
dotnet run --project "必备知识点_控制台相关/必备知识点_控制台相关.csproj"

# 编译整个解决方案
dotnet build "c#实践.slnx"
```

也可以用 Visual Studio（支持 `.slnx` 的版本）打开 `c#实践.slnx`，把目标项目设为启动项目后按 F5。解决方案内全部为相对路径，克隆到任意目录都能直接打开。

> **注意**：除 `必备知识点_随机数` 外，其余项目都要在**真实的控制台窗口**中运行。若把输出重定向到文件或管道，`Console.Clear()` 会抛出 `IOException: 句柄无效`；`SetWindowSize` / `SetBufferSize` 也只在 Windows 上受支持（编译时会出现 `CA1416` 提示）。这些都属于运行环境限制，不是代码缺陷。
